# BigBrandBucket

A modern web application built with React, Vite, and Tailwind CSS.

## Features & Tech Stack

This project uses the following technologies:
- **React 19**
- **Vite** (Build tool)
- **Tailwind CSS v4** (Styling)
- **Framer Motion** (Animations)
- **React Router DOM** (Routing)
- **Swiper** (Carousels/Sliders)
- **React Icons** (Icon library)

## Prerequisites

Make sure you have Node.js installed on your machine.

## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Run the development server**
   ```bash
   npm run dev
   ```
   This will start the local development server, usually at `http://localhost:5173`.

3. **Build for production**
   ```bash
   npm run build
   ```
   The built assets will be generated in the `dist` directory.

4. **Preview production build**
   ```bash
   npm run preview
   ```

## Project Structure

- `src/components/`: Reusable React components.
- `src/pages/`: Application pages (e.g., Portfolio, Privacy Policy, Contact).
- `src/assets/`: Static assets like images.
- `src/utils/`: Utility functions and helpers.
